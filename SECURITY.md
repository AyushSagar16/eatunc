# Security Policy

If you find a security issue, do not open a public issue with exploit details.

Use GitHub private vulnerability reporting if it is enabled for this repository. If private reporting is not available, contact the maintainer through the repository owner profile before disclosing details publicly.

When reporting an issue, include:

- A short description of the impact
- Steps to reproduce
- Affected routes, components, or environment variables
- Any suggested remediation, if you have one
